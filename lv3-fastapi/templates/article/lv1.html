Lv1:【フロントエンド】 Vueを用いておみくじサイトを作る

このレベルでは、おみくじ画面をVueで作ります。 わからない構文や API が出てきたら、まず公式ドキュメントを読んでください。 検索結果の記事を読む前に、一次情報で名前と考え方を確認するのが吉です。

まず読むもの

  • Vue 公式: Quick Start
  • Vue 公式: Template Syntax
  • Vue 公式: Reactivity Fundamentals
  • Vue 公式: Event Handling

ToDo

  1. 自己紹介サイト をVueで作る。
  2. アクセスする度に、0~99のいずれかの数字がランダムに表示されるサイト をVueで作る。
  3. 乱数サイトに機能を加え、おみくじサイトにする。（文言を考えると楽しい。）
  4. JavaScriptの「localStorage」という概念について調べる。
  5. localStorageを用いて、その日のおみくじの結果を保存する仕組みを作る

ヒント

  • 最初の自己紹介サイトは、<template> に見出しや文章を書き、<style scoped> で少し見た目を整えるところから始めると進めやすいです。
  • ランダムな数字は JavaScript の Math.random() と Math.floor() を使うと作れます。まずは 0 以上 100 未満の整数を表示してみてください。
  • 画面上の値をあとから変えたい場合は、Vue の ref を使います。ボタンで引き直すなら @click と組み合わせます。
  • おみくじ化するときは、数字の範囲ごとに「大吉」「中吉」「凶」などの文言を返す関数を作ると整理しやすいです。
  • localStorage には文字列しか保存できません。日付と結果をまとめて保存したいときは、JSON.stringify() と JSON.parse() を調べてみてください。
  • 「その日のおみくじ」にするには、今日の日付と保存済みの日付を比較します。同じ日なら保存済みの結果を使い、違う日なら新しく引く、という流れです。

困ったとき

エラー文をそのまま検索する前に、公式ドキュメント内で使われている単語を探してください。 たとえば ref で迷ったら Reactivity、クリック処理で迷ったら Event Handling を読む、という進め方です。 また、エラー文を日本語に翻訳するのも一つの手です。
